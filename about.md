# Auto Design

Select your layout blocks in the editor, then press the **black AUTO box** (in the editor's right-hand button column).
The mod automatically decorates your layout in an extreme-demon style:

- **Outline**: thin bars along every exposed block edge
- **Corner pieces**: small squares on outer corners
- **Inner detail**: an inset square in the middle of each block

All generated objects are set to **No Touch** so they never change your gameplay, and each one is undoable with Ctrl+Z.

## Settings
Toggle each style, change the outline thickness, pick a color channel for the deco, and set a safety cap on how many objects a single press can create.

## How to use
1. Build your layout with solid blocks.
2. Select the blocks (swipe / select-all).
3. Press the black **AUTO** box.
